# GLAZE UI V1.2 adoption

GoreeCloud App Store Development targets the current Stable **GLAZE UI V1.2 / 1.2.0** release at Stable promotion merge revision `f285b9145e27e6e7027b075c37299d101945c272`, with V1.2 source-qualification anchor `b0eadf9a60f73d45caffb62ffc7e9e0334cddc97`.

The governing material rule is **Neutral glass is the material. Color is an accent.** The repository maps Android Jetpack Compose and the first-party Web client to neutral Frost White / Pearl / smoke / graphite material roles with bounded Ice Blue atmosphere/accent. Historical Deep Teal and Soft Amber are no longer substrate/material defaults. The Development amber notice remains a bounded status accent rather than a glass material. Environmental/user-content sampling remains disabled, nested backdrop blur is disabled, Glaze Motion is not consumed, and App Store UI remains in **Application** system-shell scope rather than claiming Control Center, Universal Search, System Panel, or Critical System authority.

Android retains Light/Dark behavior plus a Deep Dark source palette whose runtime selection policy remains pending. The Web client retains Light/Dark runtime behavior and a Deep Dark source contract with runtime selection still pending. Ordinary interaction floors remain 48dp/48px, with the Android Touch Assistance target floor recorded at 56dp where applicable.

This is an **adoption candidate**, not accepted application conformance. V1.1 rendered evidence is historical and does not transfer to V1.2. Android/Web rendered acceptance for this exact migration, native/assistive-technology accessibility, representative physical-device/target review, supported form factors, cross-browser evidence where required, localization acceptance, Human Visual Excellence, production signing, release approval, and production acceptance remain pending.
