# GLAZE UI V1.3 adoption

GoreeCloud App Store Development targets current Stable **GLAZE UI V1.3 / 1.3.0 — Adaptive Resonance**.

Exact shared design-system anchors:

- Stable release tag: `v1.3.0`
- Stable release revision: `ff34f232f295c9dcb07e4c681f66d4104d0b9323`
- Integrated V1.3 source-qualification anchor: `fc7cc91d2eace8da2371371c2855c24cbcb326a1`
- Immediate rollback baseline: GLAZE UI V1.2 / `1.2.0`

The App Store maps V1.3 across all currently supported Development clients: Android (Jetpack Compose), Linux (GTK 4 + libadwaita), and Web (standards HTML/CSS/ES modules).

The material boundary is the V1.3 Stable rule: **Neutral glass remains the material foundation. Adaptive expression is contextual, bounded, and subordinate to meaning, accessibility, and task completion.** Android uses Frost White/Pearl neutral material with bounded Ice Blue interaction accent. Linux uses host-theme neutral material with bounded host/Ice Blue accent. Web uses the same neutral Frost/Pearl foundation. Development amber remains status-only and is not general material.

Adaptive expression is deliberately fail-closed in this migration. The App Store does not sample user content, wallpaper, environment, identity data, catalog semantics, or security/privacy state to derive presentation. Adaptive color never carries entitlement, trust, installation, availability, privacy, security, recovery, selection, focus, or authorization truth.

This is an **adoption candidate**, not accepted application conformance. Prior V1.1 rendered evidence is retained only as historical provenance and does not transfer to V1.3. Fresh consumer-local rendered/interaction validation, native and browser accessibility, representative Android/Linux/Web target review, supported form-factor coverage, performance, rollback, Human Visual Excellence, production platform-system integration, protected signing, Release Candidate approval, and production acceptance remain pending. Glaze Motion is not consumed.
